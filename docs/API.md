# API Specification

All backend endpoints are strictly versioned under `/v1` and return JSON with standard error envelopes. Authentication is performed via Firebase Anonymous Auth JWT Bearer tokens in the `Authorization: Bearer <token>` header.

## Error Format
```json
{
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "The requested track could not be found.",
    "details": {}
  }
}
```

## 1. Authentication & User Profile
- **`GET /v1/me`**
  - **Headers**: `Authorization: Bearer <firebase_token>`
  - **Response**:
    ```json
    {
      "user_id": "anon_9a87f82b",
      "created_at": "2026-09-29T15:00:00Z",
      "settings": {
        "audio_quality": "high",
        "private_session": false
      }
    }
    ```
- **`DELETE /v1/me`**
  - Completely purges all user data, playlists, likes, and interaction records (GDPR/Privacy right to erasure).
  - **Response**: `204 No Content`

## 2. Music Catalog & Search
- **`GET /v1/tracks/{track_id}`**
  - Fetches normalized track metadata, verified stream URL, and licensing information.
  - **Response**:
    ```json
    {
      "id": "trk_jamendo_182940",
      "title": "Ambient Journey",
      "artist": {
        "id": "art_928",
        "name": "Soundscape Creator"
      },
      "album": {
        "id": "alb_482",
        "title": "Nocturnal Echoes"
      },
      "duration": 214,
      "audio_url": "https://stream.jamendo.com/?trackid=182940&format=mp32",
      "artwork_url": "https://usercontent.jamendo.com?artwork=182940.jpg",
      "license": "CC-BY-SA 4.0",
      "source_provider": "jamendo"
    }
    ```
- **`GET /v1/search?q={query}&type={track|artist|album}&limit=20&offset=0`**
  - Returns unified search results aggregated from authorized music provider adapters.

- **`GET /v1/explore/trending`**
  - Returns trending and popular tracks across the catalog.

## 3. Playlists & Library
- **`GET /v1/me/library/likes`**: Returns track IDs and metadata favorited by the pseudonymous user.
- **`POST /v1/me/library/likes/{track_id}`**: Adds track to user favorites.
- **`DELETE /v1/me/library/likes/{track_id}`**: Removes track from favorites.
- **`GET /v1/me/playlists`**: Returns playlists created by the user.
- **`POST /v1/me/playlists`**: Creates a playlist (`{"name": "Focus Flow"}`).
- **`POST /v1/me/playlists/{playlist_id}/tracks`**: Appends track to playlist.
- **`DELETE /v1/me/playlists/{playlist_id}/tracks/{track_id}`**: Removes track from playlist.

## 4. Telemetry & Recommendations
- **`POST /v1/telemetry/events`**
  - Ingests pseudonymous interaction events for the recommendation engine.
  - **Payload**:
    ```json
    {
      "events": [
        {
          "event_type": "play",
          "track_id": "trk_jamendo_182940",
          "timestamp": "2026-09-29T15:02:10Z",
          "playback_duration_seconds": 180,
          "completed": false,
          "source": "discovery"
        }
      ]
    }
    ```
- **`GET /v1/recommendations/personalized?limit=20`**
  - Returns personalized recommended tracks generated by the recommendation engine based on user interaction history.
